# AdmitDay VPS data-refresh cron (issue #176)
#
# Decision (Inna, 2026-09-18, option B / #175): data PRs merge automatically,
# with no waiting period. The VPS never writes to Postgres -- it only opens
# and merges a data PR; Vercel's daily cron loads the merged data from there.
#
# Install on the VPS:
#   crontab -l | { cat; cat scripts/vps-data-cron.txt; } | crontab -
#
# All times are America/New_York. If your cron does not support the CRON_TZ
# variable, convert these entries to your server's local time before
# installing.
CRON_TZ=America/New_York

# Admissions season (September - March): every Monday, open a data PR at
# 09:00, then merge it at 09:30 (only if CI's "test" check is green and the
# PR changes exactly the two data files).
0 9 * 9-12,1-3 1 cd /root/app && ./scripts/vps-data-refresh.sh pr
30 9 * 9-12,1-3 1 cd /root/app && ./scripts/vps-data-refresh.sh merge

# Off-season (April - August): same pr/merge pair, but only on the first
# Monday of the month. Cron's day-of-month and day-of-week fields are OR'd
# together, not AND'd, so "first Monday" can't be expressed as a single cron
# field combination -- every Monday fires and the inline date check below
# limits execution to day-of-month 1-7.
0 9 * 4-8 1 [ "$(date +\%d)" -le 7 ] && cd /root/app && ./scripts/vps-data-refresh.sh pr
30 9 * 4-8 1 [ "$(date +\%d)" -le 7 ] && cd /root/app && ./scripts/vps-data-refresh.sh merge
