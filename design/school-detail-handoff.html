Handoff: Admit Day — school detail (/school/[dbn])

Overview

The screen a parent lands on after clicking a school in /find. It is the page where the product either earns trust or loses it, so it obeys one rule above all others:

Every number on this page is a value the DOE published. Nothing is computed, scored, rated, ranked, or estimated. There is no admissions-odds language anywhere. Research showed parents ignore AI-written descriptions as "too general," and one lost trust because the app gave no signal of selectivity. The answer is not a friendlier prose paragraph or a derived rating — it is 4.1 applicants per seat in mono, unlabelled by opinion, and a visible "last verified" date. Restraint is the feature.

Target codebase: Next.js 14 App Router + React + Tailwind, tokens already in tailwind.config.ts from the /find handoff. Data from schools (dbn TEXT PRIMARY KEY, data JSONB).

About the design files

school-detail.html is a design reference created in HTML — intended look and layout, not production code. Recreate it with the codebase's Tailwind tokens and App Router patterns; do not paste the markup in. All school content is placeholder (Brooklyn Tech and a composite small school); real values come from Postgres.

Fidelity: high. Colors, type, spacing and layout are final. Interactions are indicated, not implemented.

Inherited system — unchanged from /find

Radius 0 everywhere. No shadows. Separation by 1px rules, never cards. One accent: #1D4ED8.

Tokens: ink #0B0B0C, ink-2 #2A2A2F, muted #55555A, faint #8A8A90, rule #E8E8E4, rule-light #F0F0EC, border #DEDEDA, surface #FFFFFF, surface-2 #FAFAF8, accent #1D4ED8, accent-bg #EEF2FF, accent-border #C7D2FE, gem #0F7B5A / gem-bg #F0F8F5 / gem-border #BFE3D5.

Three faces, three jobs — Space Grotesk 700 for the page title (school name) and the Admit wordmark only, never in a paragraph; Libre Franklin 400/500/700 for everything read; JetBrains Mono for all numbers, codes, transit bullets and uppercase eyebrows; Newsreader italic 500 for the Day in the wordmark only.

Section eyebrow, used for every section label on this page: JetBrains Mono, 11px, uppercase, letter-spacing .12em, faint.

1120px max width, centered. Same header: 9px accent dot + wordmark, nav Find / My Schools (with mono saved count in accent) / Readiness, active item ink 500 with border-bottom: 2px solid accent.

Design decisions (and why)

Hierarchy — what a parent scans first. Name → track badges → the numbers → what's required → programs → activities → transit. So the order is exactly that, top to bottom. The numbers sit above the two-column split, full width, immediately under the title: the selectivity signal is the first thing the eye lands on after the name, which is the specific failure the research surfaced. Programs and requirements come next because they are the decision content; activities are third because they are confirmation ("why did this match my ask"); transit and provenance are reference, so they go in the rail.

Stat row, not a table. A table implies comparison between rows and invites a "score" column. A bordered grid of equal cells — 4 across, gap: 1px on a rule background so the dividers are the gap — reads as a set of independent facts, aligns mono digits into columns, and degrades by simply having fewer cells. The final cell of the grid is a surface-2 note cell: "DOE reported figures. We publish them as given and do not score or rank them." It fills the grid's last slot and states the principle where the numbers are.

Two columns, but only below the numbers. Header, title and stats are full-width single-column; the body splits 1fr / 316px with border-right: 1px solid rule on the main column. 316px matches the /find filter rail exactly, so the two screens share a spine. Decision content is in the main column; the rail holds Getting there, Also on your list, Provenance.

Missing data — never an empty slot. Three rules:

  1. A stat with no value is not rendered. No —, no zero, no greyed card. The grid just has fewer cells.
  2. Absence is then stated once, in words, below the grid: a mono NOT REPORTED eyebrow followed by "Applicants per seat, academic score, survey score, and college & career rate are not published for this school. That is a gap in the DOE data, not a low result." That last clause is required — without it a parent reads absence as failure.
  3. A section with no content is dropped entirely (5b has no AP/PSAL rows), and the fact is stated in the same eyebrow + sentence pattern under the section: NOT OFFERED — "No PSAL teams and no AP courses are listed for this school." Use NOT REPORTED when the DOE simply didn't publish, NOT OFFERED when the school genuinely lacks it. Do not blur those two — one is a data gap, the other is a fact about the school.

Compare 5a and 5b in the reference: same layout, no holes.

Layout

1. Header — 18px 36px, border-bottom: 1px rule

As /find, unchanged.

2. Back band — 11px 36px, surface-2, border-bottom: 1px rule

Left: accent link ‹ Back to 31 matches · Brooklyn + Queens, Screened at 13.5px — it names the active filters so the parent knows the list is intact. Right: mono uppercase 2 OF 31 position indicator.

This band is the persistent way back. Filter state lives in the URL, so the link is the serialized query string; it must survive a hard refresh or a shared link. Do not rely on history.back().

3. Title band — grid 1fr 200px, gap 28px, 30px 36px 26px, border-bottom: 1px rule

Left column, 12px gap: school name (Space Grotesk 700, 40px, line-height 1.04, ls −0.038em, max-width 700px, text-wrap: pretty) → mono metadata line 13K430 · Fort Greene · Brooklyn (13px, faint, ls .02em) → badge row (8px gap, wrapping): one 1px ink outline badge per admissions track (13px, 5px 11px), then the hidden-gem badge when flagged (mono 10.5px uppercase, ls .08em, gem on gem-bg, 1px gem-border, 4px 8px).

Right column, 200px, 8px gap: primary Add to list (ink fill, white, 14px/500, 11px 0) and a secondary MySchools page ↗ (1px border, accent text, 10px 0). When already saved, the primary becomes a 1px ink outline reading On your list · Remove (see 5b) — same geometry as the /find row Add button in its two states, so the control is recognisable across screens.

4. The numbers — 26px 36px 28px, border-bottom: 1px rule

Eyebrow THE NUMBERS, 14px padding-bottom. Then display: grid; grid-template-columns: repeat(4, 1fr); gap: 1px; background: rule; border: 1px solid rule.

Each cell: surface, 16px 18px, 4px gap — mono value (24px, weight 500, ls −0.02em, ink) over label (Libre Franklin 10.5px, uppercase, ls .06em, faint).

Fields in order: Applicants per seat · Total students · Academic score · Survey score · Graduation rate · Attendance rate · College & career. Render only those present, in this order; the note cell always occupies the final slot.

Below the grid, when anything is missing: the NOT REPORTED line described above (12px padding-top, mono eyebrow + 13.5px muted sentence).

5. Body — grid 1fr 316px; main column has border-right: 1px solid rule

Programs — 26px 36px 28px, border-bottom: 1px rule. Eyebrow row with a right-aligned mono count. Each program is a 1fr 190px grid row, 11px 0, border-bottom: 1px rule-light (last row none): name (15px/500 ink) + admissions method (13.5px muted). Cap at 6 rows with a Show all N programs accent link; expand in place.

What's required to apply — 26px 36px 28px, border-bottom: 1px rule, 16px gap. One block per track, each border-left: 2px solid + padding-left: 16px — accent on the primary/dominant track, border grey on secondary tracks. Block heading 15px/700 naming the track and its scope (SHSAT — 8 of 9 programs). Then definition rows as 152px 1fr grids, 6px gap, 14.5px: label faint, value ink-2; dates in mono 13.5px. Fields: Test, Register by, Test dates, Grades used, Attendance, Priority, Selection — render only what exists.

Closes with a surface-2 / 1px rule strip (13px 16px): "Requirements change year to year. Confirm on the official listing before you apply." + an Open in MySchools ↗ button (1px accent border, 13.5px/500). Deep-link to the school's MySchools page when the DBN maps to one; fall back to the directory search. Never present our copy of a requirement as authoritative.

Activities — 26px 36px 30px, 18px gap. Eyebrow row; on the right, when the parent arrived from an ask, a mono MATCHED YOUR ASK label plus the matched signals as accent chips (12.5px, accent-bg / accent-border). This is the payoff for the chip mechanic on /find.

Then one 152px 1fr grid row per group, separated by padding-top: 14px; border-top: 1px solid rule-light: left is the group name (14px/500) + mono count; right is a wrapping 7px-gap chip set (13px, 5px 10px, 1px border, ink-2). Groups: PSAL sports, AP courses, Languages, Extracurriculars.

Chips that satisfy the parent's ask get the accent treatment (1px accent border, accent-bg, accent text) — e.g. Soccer, boys and Computer Science A in 5a. Cap each group at ~7 chips with a dashed +N more / See all chip (1px dashed border, faint) that expands in place. Matched chips always sort first.

6. Right rail — 316px, sections stacked, 26px 28px, divided by border-bottom: 1px rule

  • Getting there — Subway then Bus sub-labels (12.5px faint) with route bullets as mono 13px chips (4px 9px, 1px border). Square, not circular, and not MTA line colors — that would be a second and third accent. Then Address as a 92px 1fr row. Omit a missing mode and state it with the NOT REPORTED pattern (5b has no bus routes).
  • Also on your list — up to 3–4 saved schools as 14px ink links, 9px 0, border-bottom: 1px rule-light. Lets a parent move between saved schools without going back. Omit the section when the list is empty.
  • Provenance — 92px 1fr grid, 13.5px: Source (NYC DOE School Directory & MySchools), Verified (mono date), Cycle (2026–27 admissions), then a View source record ↗ accent link. Always visible, never collapsed.

7. Footer band — 16px 36px, surface-2, border-top: 1px rule

Left: ‹ Back to results. Right, 13px faint: "Admit Day publishes DOE data as reported · we do not estimate admissions chances."

States

Loading. Server-render the page; there is no client fetch for core data. If a streaming boundary is used, hold the header, back band and title band (name and DBN are known from the list) and stream the numbers and body. Do not use skeleton cards — a rules-and-rows layout flickers badly. A single surface-2 band the height of the stat grid, containing only the mono eyebrow, is enough.

Not found. Unknown or retired DBN → keep header and back band, then one centered block at 1120px: Space Grotesk title "We don't have a record for this school", one 15px muted line explaining the DBN may be retired or mistyped, and two controls: Back to results (primary) and Search all 457 schools. Return HTTP 404. Never a generic error page — the back link is the whole point.

Data error. If the row exists but data fails to parse, render the header, title band and provenance section with an honest NOT REPORTED line covering everything else, and link to MySchools. A parent should always leave with the official link.

Add / Remove. Optimistic. Primary button flips fill↔outline and label Add to list ↔ On your list · Remove; the header My Schools count increments in the same tick. Persist to localStorage until auth. On failure, revert and show one 13.5px line under the button.

Hover. Program rows and rail links take surface-2. Buttons invert (ink fill / white). Expandable +N more chips take a solid border. All transitions 120ms ease-out. No transforms, no lift.

Focus. 2px accent outline with 2px offset on every interactive element. Requirement values must be selectable text — parents copy dates.

Responsive (below ~900px)

  • The 1120px layout reflows; it never compresses. Single column below 900px.
  • The 316px rail moves below the main column, in order: Getting there → Also on your list → Provenance. It keeps its own 1px rule dividers and drops border-right.
  • Stat grid: repeat(2, 1fr) at ≤900px, 1fr at ≤520px. The note cell moves to the end as a full-width row. Stat values drop to 22px.
  • Title band stacks: name → metadata → badges → then the Add / MySchools buttons full width, side by side with a 8px gap.
  • Back band stacks to two lines (link, then position indicator) and the ‹ Back link stays first — it is the primary navigation on mobile.
  • Definition grids (152px 1fr) collapse to stacked label-over-value with a 2px gap; keep the accent left border.
  • Activities rows collapse: group name + count on its own line, chips wrapping below full width.
  • School name drops to 30px at ≤700px, 26px at ≤520px. Horizontal padding 36px → 20px.

Data shape

type School = {
  dbn: string; name: string; neighborhood?: string; borough: string;
  address?: string; subway?: string[]; bus?: string[];
  tracks: ('screened'|'screened_assessment'|'shsat'|'audition'|'ed_opt'|'open'|'zoned')[];
  isHiddenGem?: boolean;
  stats: {                    // every field optional — omit, never zero
    applicantsPerSeat?: number; totalStudents?: number;
    academicScore?: number; surveyScore?: number;
    graduationRate?: number; attendanceRate?: number; collegeCareerRate?: number;
  };
  programs: { name: string; method: string }[];
  requirements: { track: string; scope?: string; fields: { label: string; value: string }[] }[];
  activities: { psalSports?: string[]; apCourses?: string[]; languages?: string[]; extracurriculars?: string[] };
  myschoolsUrl?: string;
  provenance: { source: string; verifiedAt: string; cycle: string; sourceUrl?: string };
};

Server-side, derive notReported: string[] (present-but-empty stat labels) and notOffered: string[] so the copy lines are generated from data rather than hand-written per school. matchedSignals: string[] comes in from the /find query params and drives accent chips — the detail page must not re-call the LLM to compute it.

New primitives

Beyond the five from /find (Chip, SegmentedControl, Button, StatBlock, SchoolRow), this screen adds four:

  • StatGrid — takes the stats object, renders present cells + the note cell, returns the missing-labels list.
  • Eyebrow — mono uppercase section label.
  • DefinitionRow — 152px 1fr label/value pair, collapses on mobile.
  • NotReportedLine — mono eyebrow + sentence; variant reported | offered.

StatBlock from /find is the small stat used in list rows; StatGrid cells are its larger sibling. Consider one component with a size prop.
